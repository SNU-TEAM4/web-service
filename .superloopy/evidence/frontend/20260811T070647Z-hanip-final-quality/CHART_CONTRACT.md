# 차트 계약

## 데이터 흐름

`menus.csv` → 현재 UI 필터 → 브랜드 그룹 → 선택 지표 집계 → 내림차순 막대차트와 정확값 표

## 단위·집계

- 메뉴 수: 정수, `개`
- 알레르기 확인률: `known / rows * 100`, 소수점 첫째 자리, `%`
- 평균 단백질: 행 단순 평균, 소수점 첫째 자리, `g`
- 평균 나트륨: 행 단순 평균, 정수, `mg`

## 시각 인코딩

- 범주: Y축 브랜드명
- 값: X축 0 기준
- 표식: 단색 Apple blue 계열 막대 하나
- 정렬: 값 내림차순, 동률은 브랜드명 로케일 순
- 범례: 단일 계열이므로 생략
- 툴팁: 지표명·값·단위·표본 메뉴 수
- 접근성: 차트 제목·설명, 동일한 정보를 제공하는 HTML 표

## 실패·빈 상태

필터 결과가 0이면 차트를 그리지 않고 조건 초기화 안내를 보여준다. 품질 JSON을 불러오지 못해도 메뉴 탐색은 유지하고 데이터 안내에 제한을 표시한다.
