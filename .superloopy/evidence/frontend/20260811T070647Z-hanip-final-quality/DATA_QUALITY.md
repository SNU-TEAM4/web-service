# 데이터 품질 계약

- 원천 CSV와 Vercel 공개 CSV의 SHA-256 일치를 필수로 검증한다.
- 필수 스키마, 숫자 범위, HTTPS 출처, ISO 날짜, 수집 방식, 중복 브랜드·메뉴, 알레르기 토큰을 검증한다.
- 검증 결과는 `reports/data-quality.json`과 브라우저용 `vercel-app/public/data/quality.json`에 같은 요약으로 기록한다.
- 브라우저용 요약은 행·브랜드·검증 행·알레르기 확인 행·오류·경고·중복·브랜드별 커버리지·출처 기준일·미러 일치만 노출한다.
- `fat`와 `carbs`라는 기존 CSV 호환 필드는 실제 공식 라벨 의미가 각각 포화지방과 당류임을 UI 모델에서 `saturatedFat`, `sugars`로 해석한다.
- 품질 경고는 숨기지 않는다. 현재 1개 행뿐인 파리바게뜨는 낮은 브랜드 커버리지로 표시한다.
