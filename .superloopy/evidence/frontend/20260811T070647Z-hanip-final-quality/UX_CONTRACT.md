# UX 계약

## 핵심 작업

사용자는 피해야 할 알레르기와 영양 한도를 설정하고, 남은 메뉴를 브랜드별로 탐색·비교한 뒤 장바구니에 담고 공식 원문을 확인할 수 있어야 한다.

## 보존할 동작

- 추천 메뉴, 장바구니, 주변 매장, 브랜드 비교, 데이터 안내의 5개 탭과 라벨
- 알레르기·브랜드·프로필·영양 필터
- 공식 원문은 현재 탭의 일반 링크로 이동
- 카카오 장소 검색·현재 위치·반경 변경
- 장바구니 합산과 수량 변경

## 개선할 계약

- 장바구니 식별자는 행 번호가 아닌 `브랜드 + 메뉴명`의 안정 키를 사용한다.
- 조건 서랍은 열릴 때 닫기 버튼에 포커스를 주고, 닫힐 때 시작 버튼으로 포커스를 돌려준다.
- 탭은 `ArrowLeft`, `ArrowRight`, `Home`, `End`로 이동하며 탭/패널 관계를 `aria-controls`로 노출한다.
- 모든 선택 칩은 `aria-pressed`로 상태를 전달한다.
- 빈 결과에는 조건 초기화라는 직접 복구 동작을 제공한다.
- 브랜드 비교는 한 번에 하나의 단위를 사용하고 정확값 표와 표본 수를 함께 제공한다.

## 안전 문구

- 알레르기 미확인 행은 알레르기 필터가 선택되면 추천에서 제외한다.
- ‘미표기’는 ‘없음’으로 해석하지 않는다.
- 영양값은 제품·매장·시점에 따라 달라질 수 있으며 심한 알레르기는 주문 전 공식 원문과 매장 확인이 필요하다.
