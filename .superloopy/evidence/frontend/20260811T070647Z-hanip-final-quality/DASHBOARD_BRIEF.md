# 비교 대시보드 브리프

- 결정: 현재 조건 안에서 어느 브랜드를 더 살펴볼지, 그리고 알레르기 확인 범위가 충분한지 판단한다.
- 주요 사용자: 메뉴를 고르는 방문자와 데이터 신뢰도를 설명하는 발표자
- 필터: 선택 브랜드, 알레르기, 최대 열량, 최소 단백질, 최대 나트륨, 검색어
- 지표:
  - 조건 통과 메뉴 수(개): 현재 필터를 통과한 행 수
  - 알레르기 확인률(%): 현재 필터 행 중 `allergen_known=true` 비율
  - 평균 단백질(g): 현재 필터 행의 단백질 단순 평균
  - 평균 나트륨(mg): 현재 필터 행의 나트륨 단순 평균
- 정확값 표: 브랜드, 선택 지표, 표본 메뉴 수, 알레르기 확인 행/전체 행
- 검증: 0 기준선, 단일 단위, 내림차순, 빈 상태, 표본 수와 반올림 규칙 표시
- 제외: 서로 다른 단위를 한 축에 혼합한 복합 점수, 근거 없는 건강 점수, 3D·그라데이션 막대
