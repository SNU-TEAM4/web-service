## 1) 구조·내용 파악

- `app.py`: 실제 배포된 Streamlit 앱. 필터, 장바구니, 지도, 브랜드·메뉴 비교, 데이터 안내를 포함합니다.
- `vercel-app`: 반응형 Next.js 앱. CSV를 클라이언트에서 읽고 Recharts와 카카오 API를 사용합니다.
- `scripts/update_official_data.py`: 9개 브랜드 공식 API·HTML·이미지 표 수집기입니다.
- `data/menus.csv`, `vercel-app/public/data/menus.csv`: 두 앱이 소비하는 동일 데이터 복사본입니다.
- 실제 배포 `https://hanip-ansim.streamlit.app/`와 Vercel Production `https://web-service-snu.vercel.app/`를 Chrome에서 확인했습니다. 개선 브랜치는 Vercel Preview `Ready`이며 로그인된 Chrome에서 정상 로드됐습니다.

## 2) 평가

### 데이터

장점은 모든 행에 공식 HTTPS 출처가 있고 `(brand, menu)` 중복이 없었다는 점입니다. 반면 개선 전 데이터에는 롯데리아 병합 셀 해석 오류, 날짜 형식 혼재, 수집일과 공식 개정일의 의미 혼재, 두 CSV를 따로 갱신하는 구조가 있었습니다. 알레르기 전용 출처도 대부분 별도 필드로 남지 않았습니다.

### 시각화

브랜드 비교는 유용했지만 브랜드명이 많은 세로 막대는 좁았고 정확한 값을 보조하는 표가 없었습니다. 메뉴 상세 레이더는 선택 집합의 최댓값에 따라 축이 바뀌고 단백질과 나트륨처럼 방향이 다른 지표를 같은 “큰 면적”으로 표현해 건강함처럼 오해할 수 있었습니다.

### 웹·배포

Streamlit 실배포와 반응형 Next.js 구현은 강점입니다. 개선 전 Next.js는 CSV 실패·파싱 오류·손상된 `localStorage`를 처리하지 않았고, 지도 API 실패를 빈 결과처럼 보였습니다. 알레르기 선택지는 CSV 15종 중 10종뿐이었습니다. Next.js 15 설치 상태에는 높은 심각도 배포 의존성 취약점 3건도 있었습니다.

### AI·발표

AI를 어디에 사용했고 어떤 결과를 사람이 검증했는지 기록이 없었습니다. 발표자가 “추천이 왜 안전한가”를 설명할 데이터 계보, 실패 전후 수치, 한계가 한 화면에 정리되지 않았습니다.

## 3) 평가 기반 대안

1. 데이터 갱신은 “수집 → 정규화 → 검증 → 두 대상 동시 저장”의 원자적 파이프라인으로 바꿉니다.
2. 레이더를 1일 참고치 대비 그룹 막대로 바꾸고, 브랜드 비교는 가로 정렬과 값 표를 함께 제공합니다.
3. Next.js는 로딩·실패·빈 결과를 서로 구분하고 공식 출처와 기준일을 메뉴 및 데이터 안내에 노출합니다.
4. AI 활용은 코드 생성 사실보다 문제 발견, 공식 자료 대조, 자동 검사, Chrome 사용자 여정 검증의 증거를 발표합니다.
5. CI에서 Python 데이터 게이트와 Next.js lint/build/security audit을 반복합니다.

## 4) 대안 적용 결과

- 롯데리아 `rowspan` 파서를 수정해 공식 2026-07-16 표를 포함한 631행을 재수집했습니다.
- `source_date_type`, `collected_at`, `collection_method`, `allergy_source_url`을 추가했습니다.
- 품질 보고서: 631행, 9브랜드, 오류 0, 중복 0, 경고 1, 두 CSV SHA-256 동일.
- 경고 1건은 파리바게뜨 1행이라는 실제 범위 한계이며 숨기지 않았습니다.
- 15종 알레르기 필터, CSV·지도 오류 상태, 손상 장바구니 복구, 탭 ARIA, 버튼 이름을 적용했습니다.
- 브랜드 비교를 가로 막대와 정확한 값 표로, 상세 비교를 성인 1일 참고치 대비 막대로 변경했습니다.
- Next.js 16.3.0·React 19.2.8·Recharts 3.10.1로 갱신했습니다. ESLint·프로덕션 빌드 통과, npm 배포 취약점 0건입니다.
- 실제 Streamlit과 Vercel Production을 확인했고 변경 브랜치의 Vercel Preview도 배포됐습니다. 다만 Preview는 로그인 보호가 적용되어 익명 공개 상태가 아니며, 카카오 키가 없어 지도·매장 검색의 실제 외부 API 성공 여정은 남았습니다.
