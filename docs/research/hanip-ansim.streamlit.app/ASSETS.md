# 자산 목록

## 사용 자산

- `vercel-app/public/logos/`: 프로젝트가 수집한 브랜드 로고.
- `vercel-app/public/data/menus.csv`: 공식 출처 기반 메뉴 데이터.
- Lucide 아이콘: 기존 프로젝트 의존성 범위.
- 카카오맵 SDK: 위치와 매장 표시.

## 사용하지 않는 자산

- Apple 로고, 제품 이미지, Apple 카피, Apple 전용 폰트 파일.
- 실제 제품 화면처럼 오인될 수 있는 재구성 이미지.
