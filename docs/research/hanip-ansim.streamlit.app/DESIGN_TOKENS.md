# 디자인 토큰

## Apple 참고값

- 본문 잉크: `#1d1d1f`
- 표면 회색: `#f5f5f7`
- CTA 파랑: `#0071e3`
- 내비게이션: 44px, `rgba(250,250,252,.8)`
- 히어로: 56px/600, 카드 제목 40px/600
- 대형 카드 간격: 12px, CTA radius: 999px

## 한입안심 변환값

- 잉크: `#1d1d1f`
- 보조 글자: `#6e6e73`
- 캔버스: `#f5f5f7`
- 표면: `#ffffff`
- 행동: `#0071e3`
- 안전/신뢰: `#18864b`
- 위험: `#b42318`
- 카드 radius: 24~32px
- 컨트롤 radius: 12~999px
- 페이지 폭: 최대 1440px, 본문 폭 1180px
- 모션: 180~420ms, transform/opacity 중심

## 글꼴

Apple 전용 SF 글꼴 파일은 복제하지 않는다. 시스템에 존재할 때만 `-apple-system`, `BlinkMacSystemFont`, `Apple SD Gothic Neo` 순으로 사용하고 웹 안전 폴백을 둔다.
