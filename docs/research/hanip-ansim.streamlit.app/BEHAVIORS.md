# 한입안심 동작 기록

## 필수 사용자 흐름

1. 필터 버튼으로 조건 패널을 연다.
2. 알레르기·브랜드·영양 범위를 바꾸면 추천 수가 즉시 갱신된다.
3. 브랜드 카드를 펼치고 메뉴를 장바구니에 담는다.
4. 장바구니에서 수량을 바꾸면 영양 합계가 즉시 갱신된다.
5. 기능 탭으로 추천·장바구니·지도·비교·데이터 안내를 전환한다.
6. 장소 또는 현재 위치로 주변 매장을 검색한다.

## 상태와 피드백

- 데이터 로딩/성공/실패를 별도 상태로 노출한다.
- 메뉴 추가 시 짧은 확인 모션과 텍스트를 보여준다.
- 검색 결과 없음, 지도 API 키 없음, 위치 권한 거부, 네트워크 실패를 빈 화면과 구분한다.
- 키보드 포커스는 모든 버튼·링크·입력에 시각적으로 나타난다.
- reduced motion 환경에서는 pulse·scale·slide 애니메이션을 제거한다.

## 반응형

- 데스크톱: 넓은 중앙 콘텐츠, 3~4열 핵심 수치, 2열 메뉴 카드.
- 태블릿: 2열 핵심 수치, 단일 열 메뉴 카드, 필터 drawer.
- 모바일: 1열 핵심 수치, 가로 스크롤 탭, 전체 폭 drawer와 카드.
