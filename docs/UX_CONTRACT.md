# UX 계약

## 핵심 사용자 여정

1. 사용자는 공식 데이터의 행 수·브랜드 수·최신 기준일을 확인한다.
2. 피해야 할 알레르기 15종과 영양 조건을 선택한다.
3. 공식 알레르기 정보가 없는 메뉴는 알레르기 조건이 있을 때 자동 제외된다.
4. 추천 메뉴의 영양 요약과 공식 출처·기준일을 확인한다.
5. 브랜드 비교에서 순위와 정확한 값 표를 함께 확인한다.
6. 장바구니 또는 주변 매장으로 다음 행동을 이어간다.

## 상태 계약

| 상태 | 사용자에게 보여줄 것 |
|---|---|
| CSV 로딩 | 진행 중임을 알리는 명시적 상태 |
| CSV/파싱 실패 | 오류 원인 요약과 다시 시도 버튼 |
| 필터 결과 0건 | 조건을 넓히라는 안내 |
| 지도 API 실패 | 빈 결과가 아닌 실패 메시지 |
| 매장 0건 | 반경·브랜드 변경 제안 |
| 알레르기 미표기 | “없음”이 아니라 “정보 미표기” |

## 접근성·반응형

- 기능 전환은 `tablist`/`tab`과 `aria-selected`를 사용합니다.
- 아이콘 전용 수량·삭제 버튼에는 메뉴명이 포함된 접근 가능한 이름을 제공합니다.
- 색만으로 수치를 전달하지 않고 차트 아래 정확한 값 표를 제공합니다.
- 900px 이하에서 필터는 오버레이 사이드바가 되고, 520px 이하에서 카드·영양 합계는 한 열로 정렬합니다.
